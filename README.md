# 🚗 HW Radar

HW Radar automatically monitors online stores for new Hot Wheels products and sends instant notifications to Discord.

## Current Features

- ✅ SMYK monitoring
- ✅ Product memory
- ✅ Discord notifications
- ✅ Keyword filtering

## Planned Features

- 🚧 Noriel monitoring
- 🚧 GitHub Actions
- 🚧 Email notifications
- 🚧 Price history
